# 👟 Jerry Shoes Outlet Web Application

A fully responsive, production-ready E-Commerce Cloud Application built entirely in Python using **Streamlit**. Designed with strict state validations, automated inventory controls, sequential order fulfillment mechanics, and instant SMTP email warning notifications.

## 🚀 Key Functional Features

* **Dynamic Product Catalog:** Interactive storefront grid rendering with real-time currency pricing formats (PKR).
* **Role-Based Access Matrix (Admin Control):** Hidden sidebar administrative workflow entry point unlocked securely via secure passwords configuration strings.
* **Dynamic Inventory Engineering:** Admins can append, alter, adjust values, prices, or change availability flags. This instantly overrides state attributes for consumers across pages.
* **Sequential Multi-Step Order Verification Wizard:** Guarded data loops step users across multi-tier validations ensuring empty carts or missing address entries explicitly halt progression paths.
* **SMTP Service Integration:** Automatic email execution framework forwarding order manifests directly to system operators upon confirmation.

## 🛠️ Local System Installation Strategy

1.  **Clone the Repository Engine:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/jerry-shoes-outlet.git](https://github.com/YOUR_USERNAME/jerry-shoes-outlet.git)
    cd jerry-shoes-outlet
    ```

2.  **Environment Isolation & Initialization:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows platform use: venv\Scripts\activate
    ```

3.  **Dependency Alignment:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Local Development Run Execution:**
    ```bash
    streamlit run app.py
    ```
